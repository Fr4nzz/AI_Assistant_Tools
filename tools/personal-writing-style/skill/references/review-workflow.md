# Review workflow

Use this workflow when the user wants to inspect and approve changes.

Work in small, coherent units. For a manuscript, begin with one paragraph at a time. Show the current text, one recommended revision, and a short reason tied to meaning, clarity, structure, or voice. Offer alternatives only when they represent a real choice in emphasis or interpretation.

When visual comparison helps, bold only the wording that changed in each version. Keep the decision small enough to judge. Wait for the user's response before treating a proposed phrase as a preference or applying it across the document.

Separate findings by the decision they require:

- factual or scientific accuracy
- meaning and scope
- paragraph structure
- sentence clarity
- voice or rhythm
- optional polish

An accepted edit without comment provides weak evidence. Record an enduring preference when the user states it, explains it, or repeats the same correction. If later feedback conflicts, follow the later instruction and mark the older guidance as superseded.
