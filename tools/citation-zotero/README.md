# Citation Zotero

Installs a Codex skill for Zotero-backed citation workflows. It supports safe
library lookup, citation-key validation, BibTeX/CSL workflows, static `.docx`
bibliography generation, and user-finalized active Zotero citation workflows
through official plugins such as ODF/DOCX Scan.

The skill does not install Zotero itself. Install Zotero Desktop and Better
BibTeX separately if you want stable citation keys.

For live Zotero fields in Word, LibreOffice, or Google Docs, the skill prepares
the document and sources but relies on verified Zotero integrations for final
conversion or insertion.
